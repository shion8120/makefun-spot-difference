Moonlit Harbor: a spot-the-difference game set in a moonlit harbor, drawn entirely in code. Three hand-built night scenes (Lantern Quay, Midnight Tide, Starfall Before Dawn) hide exactly ten differences each: click a difference on either picture to ring it, name it and count it down in the header. Wrong clicks cost five seconds, hints are limited, and finishing a level unlocks the next. Keyboard: H hint, P pause, M sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
